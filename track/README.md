# 🐍 KodNest Python Learning Track

A structured, week-by-week Python learning journey — from language fundamentals to real-world application development.

---

## 📁 Structure

```
track/
├── README.md         ← You are here
├── progress.md       ← Daily progress log
├── weeks/
│   └── week-01-language-bridge/
│       ├── day-01/
│       ├── day-02/
│       ├── day-03/
│       ├── day-04/
│       └── day-05/
```

---

## 🗺️ Curriculum Overview

| Week | Theme | Topics |
|------|-------|--------|
| 01   | Language Bridge | Python syntax, data types, control flow, functions & OOP basics |

---

## 🚀 How to Use

1. Navigate to the current week's folder
2. Read the week's `README.md` for goals and context
3. Work through each `day-XX/` folder in order
4. Update `progress.md` daily

---

> 💡 Each day folder contains exercises, notes, and any code written during class.
